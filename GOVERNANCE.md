# Governance

Local Prompt Studio currently uses a maintainer-led model.

- Qiaoxi Guo (`breadtitor`) is the founding maintainer and release manager.
- Decisions are discussed in public issues or pull requests whenever security and privacy allow.
- Maintainers evaluate changes for user value, licensing, model neutrality, privacy, test
  coverage, and long-term maintenance cost.
- A substantial or breaking change should begin with an issue and a short design proposal.
- Additional maintainers may be invited after sustained, constructive contributions and
  demonstrated care for the project's trust boundary.

Security reports and private user data are the exceptions to public-by-default discussion.
