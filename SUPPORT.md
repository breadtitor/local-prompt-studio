# Support

Use GitHub Discussions for setup questions and Skill-authoring ideas once Discussions are enabled.
Use the issue templates for reproducible bugs and focused feature proposals. Security reports
must follow [SECURITY.md](SECURITY.md), not a public issue.

This volunteer-maintained project does not guarantee response or resolution times. Include your
OS, Python version, interface, local server name and version, a synthetic reproduction, and the
output of `local-prompt-studio --skill PATH --inspect-skill` when relevant. Never publish API keys,
private prompts, history records, or sensitive media.
