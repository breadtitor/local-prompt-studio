# Required output format

Return exactly these Markdown headings in this order:

### Global Metadata

Describe the genre family, tempo character, groove, emotional movement, core sound palette, and
overall production profile. Use an exact BPM, key, or scale only when the brief supports it.

### Vocal Details

For vocal music, describe the lead configuration, timbre, register, delivery, backing vocals, and
restrained effects. For instrumental music, state that it is instrumental and identify the sound
carrying the lead melodic role.

### Arrangement

Describe a section-by-section timeline. Make instrument entrances, exits, transitions, rhythmic
development, texture, and spatial changes concrete. Honor every bracketed section direction and
every explicit exclusion without reproducing lyric text.

Target roughly 180–350 English words unless the user asks for a different length.
